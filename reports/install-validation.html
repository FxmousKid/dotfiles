1. Turn the tool list into a complete cross-distro install manifestinstall/install-tools.sh
install/README.md

Macro change

The installer is now a package-manager-first manifest for the whole development environment, not just a collection of terminal utilities. zsh, build tools, Clang, clangd, JDK 21, Cargo, tmux and cscope are first-class dependencies, so a new machine reaches a usable editor state in one run.

Why this construction

Keeping package names in a pipe-delimited table preserves one menu and one execution path across Homebrew, DNF and apt. Two extra fields—asset filters and an archive member—handle GitHub releases without scattering per-tool branches throughout ensure_tool.

2. Make ARM64 GitHub release selection deterministic and boundedinstall/install-tools.sh
install/install-lvim.sh

Macro change

Main-manifest release downloads can no longer prompt for ambiguous assets, install a package file as if it were a binary, select the wrong CPU, or wait forever after reaching 100%. Bob gets an exact OS/architecture archive in both installers; the other tools get explicit negative filters and, where needed, an exact file inside the archive.

Why this construction

A single run_eget "$@" wrapper centralizes timeout and retry policy for install-tools.sh while preserving each argument exactly. timeout is feature-detected because it exists on Linux but not stock macOS. Two 120-second attempts bound the main fresh-machine path without making transient CDN failures permanent.

install/install-tools.sh · release policy+ EGET_FILTER='--asset ^.deb --asset ^.rpm --asset ^.AppImage --asset ^.appimage'+ run_eget() {+   attempt=1+   while [ "$attempt" -le 2 ]; do+     if have timeout; then+       timeout 120 "$EGET" "$@" && return 0+     else+       "$EGET" "$@" && return 0+     fi+     [ "$attempt" -eq 2 ] && return 1+     attempt=$((attempt + 1))+   done+ }  ...- "$EGET" $EGET_FILTER "$ghrepo" --to "$LOCAL_BIN"+ run_eget $EGET_FILTER $egetfilters "$ghrepo" --to "$LOCAL_BIN"
install/install-tools.sh + install/install-lvim.sh · exact Bob archive+ case "$(uname -s)/$(uname -m)" in+   Linux/aarch64|Linux/arm64)    asset='bob-linux-arm.zip' ;;+   Linux/x86_64|Linux/amd64)    asset='bob-linux-x86_64.zip' ;;+   Darwin/arm64|Darwin/aarch64) asset='bob-macos-arm.zip' ;;+   Darwin/x86_64|Darwin/amd64)  asset='bob-macos-x86_64.zip' ;;+ esac

Design detail: Bob calls its aarch64 archive “arm,” which cannot be inferred safely from a loose substring. Resolving the exact archive in a small case is intentionally boring and auditable. 9. Remove the macOS-only clipboard command from shared Zellij configzellij/config.kdl
zellij/README.md

Macro change

The same Zellij config now parses and copies on macOS, Linux and remote SSH sessions. The hardcoded pbcopy process was removed and the documentation now describes the portable default.

Why this construction

Leaving copy_command unset lets Zellij use OSC52, which transfers clipboard content through the terminal protocol rather than requiring a host-specific executable. A local command remains an escape hatch for terminals that do not support OSC52.
